How to enable Instagram and Facebook
Instagram

Create a Meta app with Instagram Login, then set INSTAGRAM_APP_ID, INSTAGRAM_APP_SECRET, and register http://localhost:3001/api/instagram/callback as its callback. Use an Instagram professional account and grant the app the requested publishing permissions.

Facebook Pages

Create a Meta app with Facebook Login, then set FACEBOOK_APP_ID, FACEBOOK_APP_SECRET, and register http://localhost:3001/api/facebook/callback as its callback. Grant Page access and the requested publishing permissions.

Add these values to the server’s .env file, set APP_PUBLIC_URL to a public HTTPS address for video publishing, then restart the API. Never put app secrets in browser code.
